How an idea becomes a shipped feature

My personal dashboard is built by Dash, my Claude Code agent. I steer it, and these routines keep it moving.
I decideDash does it
Vision
What each part of the app is for. Only I write it.
Specs
How it should work. Dash drafts changes of 60 lines or fewer, and I approve them.
Ideas
Mine, plus suggestions Dash files while it builds.
Features
Dash shapes them as proposals. Nothing gets built until I approve.
Steps
Each has a "done when" written before the work starts.
Build
A session builds the step, tests it and commits with its number.
Gate + CI
The same checks as CI run locally before anything reaches main.
Shipped
In the changelog, and in drafts for X that I edit and post myself.
I use it, then file notes and ideas, and the loop starts again

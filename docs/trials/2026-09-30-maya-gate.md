# Trial: how sure Jev must be before Maya writes unasked

Run 2026-09-30 on the plan owner's notes, for plan #1288 under feature #1282,
before any automatic thought exists. Jev (`jev-1.13.0`) was asked the gate
question about 200 notes and wrote nothing. Every call answered, none failed,
and the 177 calls read 147,250 input tokens, well under a cent.

**Result: set `MAYA_GATE_THRESHOLD` to 0.95.** Four of the 177 notes Jev read
clear it, and all four are the writer arguing with themselves about a question
they have not settled. At 0.94 the fifth note to pass is a set of case notes
for a class, and at 0.90 five of the 24 that pass are course records, case
notes or fiction drafts. The feature asks for "the few notes that plainly hold
a live question" and for the gate to start strict, so the line sits above the
first wrong answer. It can come down to 0.94 once the automatic thoughts have
been read, which would add four notes of the same kind and one wrong one.

## How it was run

`scripts/maya-gate-trial.ts` reads a file of notes and does what the hourly
job will do with each, using `lib/vault/maya/gate.ts`:

1. Refuse the note without a call if `whyNotRead` refuses it (the `Me/`
   folder, `Career/Job Applications/`, anything shaped like an API key) or it
   is under the map's 80-character floor.
2. Otherwise ask Jev `MAYA_GATE_QUESTION`, a yes/no: is the writer working
   something out in the note, such as an open question, a tension between two
   views or a position of their own still being argued? Jev reads the title
   and the first 4,000 characters of the body, never the path.
3. Pass the note when Jev's probability of a yes is at or above the line.

The sample was the first 200 live notes ordered by `md5(id || 'maya-gate-100')`,
after leaving out the notes `whyNotRead` refuses. The export:

```sql
select json_agg(t) from (
  select id, path, title, blob_sha, length(body) as chars, left(body, 4000) as body
  from obsidian.notes
  where user_id = '<owner>' and deleted_at is null
    and path not like 'Me/%' and path not like 'Career/Job Applications/%'
    and body !~ '(sk-ant-|sk-proj-|ghp_|AKIA[0-9A-Z]{16})'
  order by md5(id::text || 'maya-gate-100') limit 200) t;
```

It drew 105 notes from `Bulk/`, 72 from `Pending/`, 14 from `Yale/` and 9
from elsewhere. Twenty-three were under 80 characters and were not asked.

There is no reference labelling. I read the opening of every note that scored
0.85 or more and judged whether it holds a question the writer is working
out.

## What the line misses

Several notes below 0.90 plainly hold a view the writer is arguing:
`Pending/work-life balance` (0.89), `Bulk/Bureaucracy` (0.88),
`Pending/on friendship`, `Pending/Multiple perspectives` and
`Bulk/Life is a road to the self` (0.87), `Pending/on productivity` (0.86),
`Bulk/Government is not a morality regulator` (0.85). The gate misses them at
any line strict enough to keep class notes out. A miss costs little, since
Maya can still be asked from the note page.

## What the job should expect

At 0.95 about one note in forty that Jev reads gets a thought. Every live note
currently reads as changed in the last 30 days, because the vault was synced
in full this month, so the hourly job (plan #1289) needs a starting point
rather than treating all 1,293 notes as new on its first run.
